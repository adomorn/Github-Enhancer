# Changelog

## 3.0.0
- Added source-linked code basket, multi-file Markdown export and mutable-link labels.
- Added named workspaces joining pages, snippets and private notes, with reopen and Markdown export.
- Added loaded-file PR review navigation, folder/type grouping, private file notes, resume and revision-aware local marks.
- Added loaded-comment search, author/saved filters, source jumps and important-comment bookmarks.
- Added private reply drafts, reusable templates, session recovery and explicit copy-only output.
- Expanded command search to workspace notes, code evidence and private PR notes.
- Fixed out-of-snapshot code selection, grouped review traversal and focus/selection retention.
- Upgraded local schema/backups to version 2 while retaining version 1 imports.
- Fixed wide layout so repository content expands alongside the sidebar's new position.

- Add a device-local workspace for saved repositories, issues, PRs, discussions, commits, and code pages.
- Add private notes, text search, type filters, removal with Undo, and JSON backup merge.
- Add an isolated in-page workbench, redesigned toolbar popup, and settings page.
- Add contextual copy actions, repository shortcuts, and an Alt+Shift+K command search.
- Replace destructive date badges with reversible exact-date annotations, local/UTC formatting, and reading modes.
- Serialize storage mutations and validate URLs, settings, imports, and worker messages.
- Remove API token handling, API host access, scripting permission, animated themes, contributor replacements, and inaccurate API-dependent file sizes.
- Add repeatable tests, asset/syntax checks, least-privilege CI, and release packaging.
