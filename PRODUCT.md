# GitHub Enhancer

## Register
product

## Users
Developers and maintainers browsing repositories, issues, and pull requests throughout the day. They switch between investigations and want to recover their own context quickly.

## Product Purpose
A private GitHub investigation workbench: review loaded PR diffs, collect source-linked code excerpts and organize pages and notes into named workspaces. Saved pages and reading utilities support these core workflows. Works without accounts, tokens, or a server.

## Brand Personality
Focused, capable, considered. English product language for a global developer audience; date locale can follow the browser or use English/Turkish.

## Anti-references
The previous extension's floating orbs, cursor particles, continuous animation, and glass effects. Avoid duplicating GitHub's native file tree or pretending to replace its search.

## Design Principles
- Keep the user's place, not a second copy of GitHub.
- Only ask for attention when the user invokes a tool.
- Local data and transparent controls build trust.
- Preserve GitHub's native workflows and semantics.
- Fast keyboard paths complement visible controls.

## Accessibility & Inclusion
Keyboard operation, visible focus, clear labels, reduced motion, light/dark adaptation, with WCAG AA contrast as a design target; full conformance has not been audited. Never override native GitHub keyboard shortcuts.

## Decision authority
The user explicitly delegated product/design decisions and authorized discussion with independent agents. These choices combine that brief with repository analysis and competitor research.
